Transformation Manager Trainer – PWA
1. Den Ordner auf einem Webserver hosten (GitHub Pages, Netlify, Cloudflare Pages o.ä.).
2. Den HTTPS-Link auf dem iPhone in Safari öffnen.
3. Teilen -> Zum Home-Bildschirm.
4. Die App kann danach als eigenständige PWA geöffnet werden.
Hinweis: Für echtes Offline-Verhalten muss die App noch um einen Service Worker ergänzt werden; die Fragen selbst liegen bereits lokal als JSON vor.
